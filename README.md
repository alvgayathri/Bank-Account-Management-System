# Bank Account Management System

## Description
A simple OOP-based banking system that allows users to deposit, withdraw, and check balance .

## Features
- Create an account with a holder name
- Deposit money
- Withdraw money (with sufficient balance check)
- Check account balance



## Requirements
- No external libraries required.
- Works with Python 3+

## File Storage
- Transactions are not stored permanently; data resets when the program is restarted.

## Notes
- Ensure to enter valid amounts while depositing or withdrawing funds.
- The withdrawal amount should not exceed the account balance.
